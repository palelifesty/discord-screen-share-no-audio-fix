Fixes Discord screen share with no audio on Windows 10 and 11. Resolves audio capture for Chrome, Firefox, games and applications.

## Features

- Fixes no audio in Discord screen share
- Works with Chrome, Firefox and Edge
- Fixes game audio capture (Spotify, games)
- Applies correct audio capture permissions
- Resets Discord audio subsystem
- Works for both video call and Go Live

Yes, both regular screen share and Go Live are fixed.
